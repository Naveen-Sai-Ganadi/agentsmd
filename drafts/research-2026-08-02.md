# Research log — 2026-08-02

Five signals scanned for the daily loop. Focus: is the monorepo policy-as-code
wedge (decision #12 = `mono`) still uncontested after the 2026-08-01 competitor
wave?

## Signals

1. **morphllm.com / AGENTS.md Spec (2026)** — restates that "AGENTS.md is
   the closest thing the agent ecosystem has to a shared standard" and that
   *the OpenAI main repo carries 88 nested AGENTS.md files.* Confirms
   monorepo-nested is the default deployment shape, not the exception.
   <https://www.morphllm.com/agents-md-guide>

2. **codegateway.dev — "AGENTS.md for Codex CLI (2026): Lookup Order, Limits
   & Monorepo Templates"** — full write-up of *nearest-file-wins* + monorepo
   templates. Explicit statement: *"across every supported tool, the nearest
   AGENTS.md to the file being edited wins on conflict, and explicit user
   prompts override everything."* Reinforces that policy-as-code has to be
   evaluated **per package**, not per repo. Directly justifies decision #12
   = `mono`.
   <https://www.codegateway.dev/en/blog/agents-md-playbook-2026>

3. **iuriio.com — "The AGENTS.md Field Guide, 2026 edition"** — practitioner
   guide reiterating that nested files are the primary friction point. No
   tool in that guide lints across nested files. Empty niche confirmed.
   <https://www.iuriio.com/blog/posts/2026/05/agents-md-field-guide-2026>

4. **agentlint.app** — competitor. Positions as "33 data-backed checks" and
   explicitly lists CLAUDE.md, AGENTS.md, `.cursor/rules`,
   `.github/copilot-instructions.md`, CI workflows, hooks, `.gitignore`.
   Broader scope than us but **still single-file / repo-root only** in the
   docs — no monorepo/nested story visible. Our `mono` bet still holds.
   <https://www.agentlint.app/>

5. **morphllm — "Claude Code Reddit: What Developers Actually Say (2026)"** —
   aggregated Reddit sentiment. Two of the top three pain points map directly
   to us: **context drift** (freshness/staleness) and **MCP-server context
   consumption**. The recommended mitigation across posts is "keep CLAUDE.md
   under 200 lines" — exactly the kind of budget an `audit` dimension can
   enforce and `doctor` can surface. Consider a "size budget" check for
   v0.1.1 alongside `mono`.
   <https://www.morphllm.com/claude-code-reddit>

## Takeaways

- **Monorepo/nested is still uncontested** by named competitors (agnix,
  agentlinter, agent-audit, agents-lint, AgentLint) — decision #12 = `mono`
  gets stronger, not weaker.
- **200-line CLAUDE.md budget** is now a folk-rule with wide Reddit
  adoption. Cheap add for the audit `structure` or `freshness` dimension;
  fits inside a v0.1.1 that ships `mono`.
- **Setup friction** ("is this even wired up?") is a real, recurring
  question — validates today's `doctor` command as a real dogfood-driven
  add rather than a nice-to-have.
