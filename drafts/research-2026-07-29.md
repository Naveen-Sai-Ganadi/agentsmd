# Research log — 2026-07-29

Five fresh signals gathered on the day of the v0.1.0 tag. Focus:
positioning of `agentsmd` (single-source-of-truth + lint + audit + CI
gate) against the growing crowd of "sync-only" and "lint-only" tools.

1. **`earezki.com/agent-kit` (2026-05-29)** — "Eliminating AI Agent
   Instruction Drift with agent-kit". Yet another one-AGENTS.md-to-many
   derive-CLAUDE.md/GEMINI.md/copilot-instructions tool. Sync only, no
   audit/lint. Confirms our wedge: derivation is table stakes; the moat
   is the CI gate that fails PRs on drift.
   <https://earezki.com/ai-news/2026-05-29-one-agentsmd-for-every-coding-agent-auto-derive-claudemd-geminimd-copilot-instructions/>

2. **`codex.danielvaughan.com` (2026-05-27)** — "Agent Instruction
   Files: AGENTS.md, CLAUDE.md, and Cross-Tool Portability with Codex
   CLI". Independent post from the Codex community confirming AGENTS.md
   as the cross-tool spec. Uses ln -s pattern; would benefit from
   `agentsmd sync --apply`.
   <https://codex.danielvaughan.com/2026/05/27/agent-instruction-files-agents-md-claude-md-cross-tool-portability-codex-cli/>

3. **`morphllm.com/agents-md-guide` (2026)** — "AGENTS.md Spec (2026):
   Recommended Sections + AGENTS.md vs CLAUDE.md vs .cursorrules". Spec
   guide claims 60,000+ repos already carry an AGENTS.md and lists
   Codex, Cursor, Copilot, Gemini CLI, Aider, Windsurf, Zed as native
   readers. Useful data point for the launch post.
   <https://www.morphllm.com/agents-md-guide>

4. **`amux.io/guides/agent-config-files-compared` (2026)** — Every AI
   agent config file compared. Documents Cursor MDC frontmatter and
   nearest-file precedence in monorepos. Feeds a v0.2 monorepo mode
   requirement for `lint`/`audit` (nested AGENTS.md discovery).
   <https://amux.io/guides/agent-config-files-compared/>

5. **`agentlinter.com` (2026)** — Hosted "AgentLinter" SaaS still live,
   framed as "linter for CLAUDE.md & AI agents". Still no free CI
   action, still no audit scorecard. Confirms our niche.
   <https://agentlinter.com/>

## Takeaway

Two forces continue in the same direction as last week:
- The **sync** side is commodifying fast (`GowayLee/agent-sync`,
  `amtiYo/agents`, `dallay/agentsync`, now `earezki/agent-kit`).
- The **lint/audit-with-CI-gate** side is still empty — AgentLint and
  AgentLinter cover lint but neither offers a reusable GitHub Action
  that fails a PR on grade regression.

`agentsmd check` + `action.yml` remains uncontested. v0.1.0 shipping
today is the right moment to plant a flag.
