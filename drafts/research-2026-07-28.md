# Research log — 2026-07-28

Focus: fresh signals in AGENTS.md ecosystem since 2026-07-26.

## Signals

1. **`GowayLee/agent-sync`** — https://github.com/GowayLee/agent-sync
   OCaml CLI, sync-only, uses symlinks between `CLAUDE.md`, `GEMINI.md`, etc. No lint, no audit, no init.
   *Delta vs us:* pure sync, symlink-based (breaks on Windows). We do sync + init + lint + audit + CI, cross-platform.

2. **`amtiYo/agents`** — https://github.com/amtiYo/agents
   Broader scope: syncs MCP servers, skills, AND instructions across Codex/Claude/Gemini/Cursor/Copilot/Antigravity from a single `.agents/` source.
   *Delta vs us:* biggest positioning threat so far. They own "skills + MCP" sync; we own "config quality + CI gate." Consider a follow-up `agentsmd import --from-agents-dir` in v0.2 if they gain traction.

3. **`dallay/agentsync`** — https://github.com/dallay/agentsync
   Third symlink-based sync CLI. Same limitations as GowayLee.
   *Signal:* three symlink-sync tools now exist — market is validating the problem. None do quality gating.

4. **Claude Code issue #6235 (AGENTS.md native support)** — still open, now **5,270+ reactions** (up from 5,200 on 07-26).
   *Read:* Anthropic has not shipped native AGENTS.md read in Claude Code. Sync tooling stays load-bearing until they do.

5. **Yurukusa "does Claude Code read AGENTS.md" gist** (updated) — https://gist.github.com/yurukusa/d36197848911f025add142abefcde685
   Documents five operator-side patterns for keeping the two in sync (symlink, `@AGENTS.md` import, generated wrapper, etc.). Our `sync` generates the wrapper approach automatically — worth citing in the README.

6. **morphllm.com/agents-md-guide** and codersera + medium/data-science-collective all published fresh 2026 "AGENTS.md spec" explainers. Content velocity around the standard is high — good for organic discovery.

## Positioning takeaways

- Sync alone is now commodified (3+ tools). Our moat = **lint + audit + `check` CI gate** — nobody else has this combination.
- Symlink-based tools cannot enforce structure. Our value story tightens to: *"the only tool that fails your PR when AGENTS.md rots."*
- Consider a section in the README (or a short blog post draft) that explicitly compares symlink-sync vs. render-sync + gate. Symlink is fragile: Windows, git submodules, monorepos. We already win on all three, but haven't said so.
- amtiYo's `.agents/` scope is a possible v0.2 direction (skills + MCP sync). Not urgent, but track.
