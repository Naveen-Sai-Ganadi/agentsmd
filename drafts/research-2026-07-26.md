# Research log — 2026-07-26

Focus: is anyone else shipping CI-time enforcement for AGENTS.md / CLAUDE.md quality?

## Signals (5)

1. **`giacomo/agents-lint`** — [GitHub](https://github.com/giacomo/agents-lint) — closest overlap yet. Zero-dependency CLI that verifies AGENTS.md, CLAUDE.md, and AI-memory files "stay accurate as the repo evolves." Positions itself around detecting stale paths, dead npm scripts, outdated framework patterns, and context rot. Their pitch language ("your AGENTS.md is probably lying") is sharp — worth mimicking the frame in our positioning. Different angle from us: they focus on *stale references* (does path/script still exist?); we focus on *structure + quality scoring*. Complementary, not identical.
2. **AgentLint marketplace action** — [Marketplace](https://github.com/marketplace/actions/agentlint) and [agentlint.app](https://www.agentlint.app/) — a paid-looking SaaS-flavored lint action that audits CLAUDE.md, AGENTS.md, .cursor/rules, .github/copilot-instructions.md, CI workflows, pre-commit hooks, .gitignore. Overlap is real. Differentiation for us: open-source MIT, single dependency-free binary, `sync` (they don't have write/sync from a single source of truth as far as I can see).
3. **`agentlinter.com`** — [site](https://agentlinter.com/) — hosted linter for CLAUDE.md & AI agents. Web UI, not CI-first. Confirms the "lint AI config" niche is being commercialized. Our angle: local-first CLI + reusable action, no SaaS.
4. **Build-AGENTS.md-from-Skills action** — [Marketplace listing](https://github.com/marketplace/actions/build-agents-md-from-skills) — adjacent tool that assembles AGENTS.md from a `skills/` folder. Composable with our sync: someone could run this action to *generate* AGENTS.md, then our `check` action to *validate* it. Potential integration/blog angle.
5. **Yurukusa's Claude Code gist** — [gist link](https://gist.github.com/yurukusa/d36197848911f025add142abefcde685) — "Does Claude Code read AGENTS.md? No — it reads CLAUDE.md" — 5,200+ reactions on the referenced Claude Code issue #6235. Confirms the exact drift-pain we're solving is a top-tier community complaint. Users are asking for symlink/import patterns; our `sync` command is the "operator-side pattern" answer.

- `giacomo/agents-lint`'s framing ("your AGENTS.md is probably lying") is a good hook for the launch post. Adapt, don't copy.
